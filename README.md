# تطبيق تلاوات مدرسة أفضل العلوم

تطبيق (`afdal_uloom_tilawat`) يحفظ لكل طالب تلاواته المسجّلة في استوديو المدرسة مع ملاحظات معلمه عليها، ويسمح للطالب بتسجيل تلاوات تدريبية وإرسالها للمعلم.

## التشغيل

```bash
flutter pub get
flutter run -d chrome
```
